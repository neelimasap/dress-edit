# The Dress Edit

Static daily page of designer dress deals (Zimmermann, Self-Portrait, Marchesa, Dress the Population, Alice + Olivia, Elliatt, Helsi) in US 6 / US 8.

- `index.html` — the page (data embedded, no build step)
- `img/` — product images, stable names, refreshed daily

Regenerated each morning by `publish_dress_edit.sh` and auto-deployed by Vercel (framework: Other, no build command, output = repo root).
